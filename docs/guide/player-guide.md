# 枫丹共和国 · 玩家上手指南

> 面向玩家（非技术）的入门说明。最后更新：2026-08-13。

---

## 一、这是什么

枫丹共和国 Mod 把服务器的"国家制度"搬进游戏：你登录后会自动获得
**公民身份**和**零余额账户**，之后可以查余额、互相转账、参与土地使用、
政府任职、议会立法与法院诉讼。所有数据由服务器权威保管，客户端只负责显示。

## 二、开始之前

- 安装：把 mod 放进 `mods/` 即可；不装客户端模组也能用（所有操作走命令/聊天）。
- 第一件事：登录服务器，系统会自动为你开户（公民 + 账户）。

## 三、常用命令

所有命令以 `/fr` 开头：

| 命令 | 作用 |
|---|---|
| `/fr help` | 查看当前可用的命令分类 |
| `/fr money balance` | 查看我的余额 |
| `/fr money pay <玩家名或UUID或登记号> <金额> [备注]` | 给他人转账 |
| `/fr money history [页码]` | 查看我的收支记录 |
| `/fr citizen info` | 查看我的公民身份与政治等级 |
| `/fr court case list`、`/fr government position list` 等 | 查看各机构公开信息 |

公开登记号长这样：`10-000001-61`（水神个人）、`00-000001-95`（水神职位）。
你的个人登记号在开户后由服务器分配，可用于转账路由。

## 四、国家是怎么运转的

四大柱石（宪法框架）：

- **议会**：提案 → 投票 → 法案。不同层级的法律需要不同门槛
  （普通法过半数、组织法 2/3、宪法基本法 3/4）。
- **政府**：部门/职位/官员任命。任命与罢免是**现场职责**——
  必须到注册的政府设施终端前操作。
- **法院**：案件 → 证据 → 裁判；土地违规举报可自动立案；有复核路径。
- **中央银行**：国库与货币（现场职责，后续开放）。

**重要规则**：政治职位（如"水神"等级）不代表技术权限；重要操作必须在
对应机构实体场所现场完成，不能在聊天框里远程办公。

## 五、常见问题

- **我没装客户端模组能用吗？** 能。所有功能都走命令 + 聊天反馈。
- **转账给谁？** 支持玩家名 / UUID / 公开登记号三种方式；名字歧义时会提示
  "无法唯一解析"，不会转错人。
- **数据安全**：关键变更（开户、转账、任命、立法、裁判）都是确认式落盘，
  崩溃后不会"转账成功但丢了记录"。
- **更多帮助**：游戏内 `/fr help <模块>`；或咨询服务器管理员。
