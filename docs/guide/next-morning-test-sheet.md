- 期望：**能正常进服**（之前会被踢出，现在不再被踢）。

### 2. 邮件重启不丢

- 期望：**邮件还在**（之前重启后邮件会消失）。

## 二、水镜（传讯水镜）

### 3. 发放水镜
- 做：服务器控制台执行 `/fr communicator issue <玩家名>`。
- 期望：该玩家背包里得到一个显示「传讯水镜」的**时钟**。

### 4. 水镜重启不失效
- 做：发一个水镜 → 正常停服/重启 → 玩家用手持水镜右键空气。
- 期望：**仍能打开主菜单**（密钥持久化生效，不会重启失效）。
