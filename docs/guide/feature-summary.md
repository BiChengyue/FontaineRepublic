# 枫丹共和国 FontaineRepublic — 当前功能总览与使用限制

> 适用：develop 当前合并状态（2026-08-14，客户端首版 + 传讯水镜；交易/邮件/
> HUD/购地在途）。文档面向玩家与管理员，非技术语言。

## 一、一句话

一个国家模拟/RPG 模组：玩家有身份、钱、土地与机构（政府/议会/法院/央行），
机构操作要"到场"，水神/服务器拥有紧急权力；可选 FR 客户端提供可视化界面，
但**没装客户端或没手持传讯水镜，所有功能仍可用命令完成**。

## 二、功能清单与使用限制

### 1. 身份与公民（无位置限制，本人信息）

| 功能 | 命令 | 限制 |
|---|---|---|
| 查公民身份/政治等级 | `/fr citizen info` | 无（本人）|
| 主体登记号 | 开户后由服务器分配 | 无 |
| 水神初始绑定 | `/fr admin bootstrap subject-hydro <uuid> <理由>` | **仅本地专用服务器控制台**；不可变 |

### 2. 经济（个人账户）

| 功能 | 命令 | 限制 |
|---|---|---|
| 查余额 | `/fr money balance` | 无（本人）|
| 转账 | `/fr money pay <玩家名/UUID/登记号> <金额> [备注]` | 无位置限制；**1 秒冷却**；离线目标可收（登录后通知）|
| 流水 | `/fr money history [页]` | 无（本人）|

### 3. 央行官方职责（**必须现场**）

| 功能 | 命令 | 限制 |
|---|---|---|
| 国库总额 | `/fr bank balance` | 公开只读；明细受限 |
| 官方发钞/回收/冻结/解冻 | `/fr bank deposit|withdraw|freeze|unfreeze <目标> <金额> <区域ID> [理由]` | **必须在注册的央行区域现场**并传区域 ID；离开/超时上下文失效 |

### 4. 政府（**必须现场**）

| 功能 | 命令 | 限制 |
|---|---|---|
| 部门/职位/任命/罢免 | `/fr government ...` | **必须在政府区域现场**并传区域 ID；政治职位≠技术权限 |

### 5. 议会（**必须现场**）

| 功能 | 命令 | 限制 |
|---|---|---|
| 提案/投票/法案/守护审阅/公投/修宪 | `/fr parliament ...` | **必须在议会区域现场**；阅读/公开列表无限制 |

### 6. 法院（**必须现场**）

| 功能 | 命令 | 限制 |
|---|---|---|
| 案件/证据/裁判/复核 | `/fr court ...` | **必须在法院区域现场**；土地违规举报可自动立案 |

### 7. 土地

- 共和国地块：建造/破坏/交互权限按地块区域与访问策略由服务器判定；
- 地块信息：客户端土地视图（概况）；**个人地块创建/购地命令尚未开放**
  （在途"购地"功能将提供）。

### 8. 紧急权限（水神/控制台专属）

| 功能 | 命令 | 限制 |
|---|---|---|
| 紧急发钞/回收 | `/fr admin emergency preview ...` + `confirm <token>` | **仅水神 UUID 或专用服务器控制台**；token 单次 30 秒；原因必填（中文需加引号）；RCON/命令方块/函数/集成主机一律拒绝 |
| 检查/状态/配置 | `/fr admin emergency inspect|status|bootstrap|stage|recover` | bootstrap/recover 仅控制台；stage 水神或控制台 |

### 9. 客户端可视化（FR Client）

| 功能 | 命令/操作 | 限制 |
|---|---|---|
| 十个界面（余额/转账/流水、公民卡、历史、通知、政府、议会、法院、土地、引导） | `/frclient ...` 或主菜单 | **必须安装 FR 模组 + 手持传讯水镜** |
| 快捷入口 | 手持水镜**右键空气**开主菜单；右键玩家→转账预填；右键方块→土地视图 | 同上 |
| 无客户端平行性 | 所有 `/fr` 命令 + 聊天反馈 | 无 FR 模组/无传讯水镜不影响 |

### 10. 传讯水镜

- 显示名"传讯水镜"；**无合成表**，仅服务器管理员（水神/控制台）`/give` 发放；
- 手持才可用客户端 UI；背包持有才可收到新邮件 HUD 提醒（邮件在途）。

## 三、使用限制速查表

| 需要 | 才能 |
|---|---|
| 手持传讯水镜 + FR 客户端 | 打开 `/frclient` 可视化界面 |
| 身在央行区域 | `/fr bank` 官方职责 |
| 身在政府区域 | `/fr government` 任命/罢免 |
| 身在议会区域 | `/fr parliament` 提案/投票/法案 |
| 身在法院区域 | `/fr court` 案件/证据/裁判 |
| 水神 UUID 或控制台 | `/fr admin emergency` 全部 |
| 仅专用服务器控制台 | bootstrap / recover / 水神绑定 |
| 无限制（本人数据） | 余额、流水、转账、公民信息、公开列表 |

## 四、在途功能（未合入，完成后另行通知）

- **交易**：双人实时交易（钱+物品）、双方同意 5 秒执行、交易税=出钱方 5%；
- **邮件**：个人/机构互寄、附件（钱+物品）、邮费 10/封+附件费 100/个、
  机构免费、机构一键向全体公民发公告；
- **HUD**：背包含传讯水镜时屏幕常驻显示名称/身份/登记号/余额/未读邮件，
  可拖动调整位置；
- **购地**：右键无主方块 → 创建共和国地块并取得使用权。
