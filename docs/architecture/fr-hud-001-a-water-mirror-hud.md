# FR-HUD-001-A — 传讯水镜常驻信息 HUD（设计候选 v1.0）

> **Task ID:** FR-HUD-001-A
> **Status:** Design Candidate — 实施中（Human 需求 2026-08-14）
> **Purpose:** 背包持有传讯水镜时，屏幕常驻显示关键信息；面板位置可调整

## 1. 需求（Human）

- 只要背包里有传讯水镜，就**始终**在屏幕 HUD 显示关键信息；
- 显示内容需评估确定（名称/身份/ID/财产/未读邮件等）；
- **HUD 必须可以调整位置**。

## 2. 内容评估（推荐显示）

| 字段 | 来源（S2C 已有/待增） | 显示 |
|---|---|---|
| 名称 | 本地玩家名 | 常显 |
| 身份（公民状态/政治等级） | `CitizenInfoPacket`（缓存） | 常显 |
| 登记号 ID | `CitizenInfoPacket` | 常显 |
| 财产（余额） | `BalanceSyncPacket`（缓存） | 常显 |
| 未读邮件数 | `MailAlertPacket`（新） | 常显（角标/行）|
| 交易/邮件提醒 | `TradeStateSyncPacket`/聊天 | 临时行 |
| 土地概况（可选） | `LandInfoPacket`（缓存） | 折叠 |

- **不做**：他人余额/隐私数据、权威状态、服务器管理员数据；
- 未读邮件数在无邮件模块数据时隐藏；缓存缺失显示占位。

## 3. 可调整位置

- HUD 面板支持**拖动**：按住面板标题拖到任意屏幕位置，位置**持久化到
  客户端本地配置**（config 文件，非权威）；
- 提供重置按钮/命令（`/frclient hud reset`）；面板可折叠/透明度可配。

## 4. 数据流

- 登录/变更时 S2C 推送（余额/公民/邮件未读）；客户端缓存非权威；
- HUD 仅在有传讯水镜（背包）时渲染；无客户端/无水镜零影响。

## 5. 测试

- 内容投影（空态/占位）；位置持久化读写；门禁（背包含水镜才渲染）；
- 侧隔离；`gradlew build` 全绿。
